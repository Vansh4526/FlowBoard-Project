# FlowBoard — Smart Kanban Task Manager

FlowBoard is a responsive task-management application that helps
users organize tasks, track deadlines, and prioritize their work
through a visual Kanban workflow.

## Live Demo

[Open FlowBoard](https://flow-board-project.vercel.app/)

## Features

- Organize tasks using a Kanban workflow.
- Drag and drop tasks between workflow stages.
- Prioritize tasks based on urgency, impact, and deadlines.
- Track task deadlines.
- Persist task data using browser localStorage.
- Use the interface across different screen sizes.

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Browser localStorage

## Getting Started

1. Clone this repository from GitHub.
2. Open the project folder in VS Code.
3. Run `index.html` using a local development server,
   such as the Live Server extension.
4. Open the local URL provided by the server in your browser.
